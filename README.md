# The Historical Continuum of Hip Hop

A living, extensible archive documenting the centuries-long evolutionary continuum of oral expression, rhythmic innovation, and social commentary across the African diaspora.

## Architecture
This repository adheres strictly to the **Diátaxis framework** for information architecture[cite: 2]:
- **Tutorials & How-To Guides:** Practical, action-oriented implementation steps (Future Scope)[cite: 2].
- **Explanations (`docs/explanation/`):** Deep-dive historical contexts, starting with West African Griots to modern sample archaeology[cite: 1].
- **References (`docs/reference/` & `data/`):** Immutable historical timelines, entity relationships, and glossaries[cite: 2].

## Tech Stack
- Astro + TypeScript
- Tailwind CSS
- Markdown/MDX for content
